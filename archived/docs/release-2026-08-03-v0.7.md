## 一、重大变更

### 1.1 迁移 Squashing（68 → 8 文件）

68 个 Alembic 迁移文件压缩为 8 个（`0001_squashed_baseline` + 0062-0068），空库重建速度快 10 倍。

- 基线 1511 行，含 40 表 / 65 索引 / 3 扩展（citext, pgcrypto, vector）/ 4 角色 / 62 RLS 策略 / 89 GRANT
- 基线使用 raw SQL（pg_dump --schema-only），保留 autogenerate 无法捕获的 RLS 策略、DB roles、触发器
- `_split_sql()` 函数处理 psycopg3 async 多语句限制 + dollar-quoting + search_path 修复

### 1.2 Worker 健康检查 + 自动恢复

- `worker_process_init` signal 自动启动 9100 端口 `/health` 端点
- prefork 多进程端口冲突静默跳过
- Docker compose healthcheck + restart policy
- 独立启动脚本 `start_worker.sh` / `start_beat.sh`，自动加载 .env 环境变量
- Beat 健康检查用 celerybeat-schedule 文件时间戳

### 1.3 多租户隔离键升级

**ADR 定案：department_id 扶正为多租户隔离键，organization_id 退役。**

- 5 条核心规则：归属 / 对称层级可见性 / 管理员=root 成员 / 个人私有数据 / 结构数据全员可读
- 个人私有：`visibility_scope` + `owner_user_id`，仅 owner 可见（含管理员），单向不可逆（DB 触发器兜底）
- AI 会话不进部门树：仅创建者 + 参与者可见
- 副本语义（copy-on-share）：会话内数据副本不可回收、不随源更新
- 管理权模型：所有者 + 上级向下
- 66 处 `department_id == self._dept_id` 硬过滤改为 `.in_(visible_ids)` 向下穿透
- 前端管理权限控制：无管理权时按钮变灰
- 接口发布支持选择归属部门 + 编辑接口端点

### 1.4 数据库备份系统

**v1 pg_dump 方案**：
- backup_record 表 + ORM + Service + 6 API + Celery beat + 前端 /governance
- 三种备份类型：daily（14天）/ milestone（永久）/ pre_restore（7天）
- 回滚前自动 pre_restore 备份

**v2 PITR 升级**：
- pg_basebackup + WAL 归档 + MinIO mc mirror 联合备份
- manifest format_version v1/v2 路由
- 前端备份方法标签 + 恢复时间点选择器

## 二、新增功能

### 2.1 AI 助手分析橱窗

- 三栏布局：对话列表 260px / 消息流 flex / 分析橱窗 360px（可收起 48px）

- Plotly 科研图表：误差棒图、箱线图、三维散点图、热力图
- 块去重：唯一索引 (conversation_id, source_message_id, source_block_index)
- ai_showcase_item 表（迁移 0052）

### 2.2 AI 协作功能

- conversation_participant 表（迁移 0053），@提及 + 多人协作
- ai_message 加 mentions + sender 冗余字段
- app_user 加 avatar_url

### 2.3 AI 助手全面增强

- 流式渲染优化
- 橱窗共享（copy-on-share 副本语义）
- chart-ref 画图指令
- JSON 压缩（减少 system_context 体积）
- 对话权限控制

### 2.4 Converter 插件化重构

- 插件注册表模式：每插件一个 `converters/<name>/converter.py` + `__init__.py`
- 对外 2 个插件：`xrd_converter`（确定性）+ `llm_converter`（LLM 兜底）
- 新增 `raman_converter`（拉曼光谱确定性解析器）

- 路由模块：`packages/plugins/router.py`（后缀映射 + fallback）

### 2.5 潮线 Tideline 设计语言（水光版）

- 数据之海第二版视觉语言，取代极地雾蓝 v1
- 三条审美红线：不要斜切硬几何 / 不要大面积实色撞色 / 一种签名装饰只用一次
- 色彩：ocean.abyss（深潮蓝 #0B4A6F）+ ocean.current（潮流青 #17B8CE）
- 签名类：ocean-watermark / ocean-flow-text / ocean-water-glass / ocean-tide-enter
- 特色组件：GradLine（渐变直线）/ EcgLine（心电图）/ SiderClock（侧栏大号时钟）
- 导航选中：水光玻璃 + 左缘圆头渐变条

### 2.6 UI 改进

- Tab/侧栏选中态加深（渐变 0.16→0.38、边框 0.32→0.55）
- 作业进度按钮胶囊化
- 研发看板占比图（按 fact 数据聚合）

## 八、升级说明

### 全新部署

```bash
git clone https://github.com/spwater/irip.git
cd irip
docker compose up -d postgres redis minio
set -a && source .env && set +a
.venv/bin/alembic upgrade head    # 基线 0001 → 0068，一步到位
.venv/bin/uvicorn apps.api.main:app --reload --port 8000
bash start_worker.sh
bash start_beat.sh
bash start_frontend.sh
```

### 从 v0.3.0 升级

```bash
git pull origin main
# 数据库已在 0068 (head)，无需额外迁移
# 重启 Worker 和 Beat 以加载 healthcheck 代码
bash start_worker.sh
bash start_beat.sh
```
