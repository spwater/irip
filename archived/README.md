# IRIP 历史资料归档

本目录保存 2026-08-08 文档收敛前形成的 PRD、架构稿、评审、发布报告、验收快照、旧计划和配套 Mermaid 图。

这些文件没有删除，目录结构尽量镜像原路径：

- 原根目录报告位于 `archived/`；
- 原 `docs/...` 文件位于 `archived/docs/...`；
- 原 `deliverables/...` 文件位于 `archived/deliverables/...`。

历史材料用于追溯需求演变、设计理由和过去某一时点的判断。它们可能与当前代码、迁移、命令、测试数量或安全状态不一致，因此不能作为当前实现依据。

当前项目状态从 [`docs/STAGE_DELIVERY.md`](../docs/STAGE_DELIVERY.md) 开始阅读。需要实际操作时，再读取其中列出的常驻文档。

## 归档分类

- `archived/docs/prd*`、`archived/docs/arch*`：各阶段需求与架构设计；
- `archived/docs/refactor/`：一次性重构设计与配套图；
- `archived/docs/acceptance/`：历史验收快照；
- `archived/docs/release-*`：历史发布记录；
- `archived/docs/*review*`、`archived/deliverables/*review*`：代码和架构评审；
- `archived/deliverables/`：既往交付稿、整改稿与图表；
- `archived/code-assessment-2026-08-08.md`、`archived/squash-report.md`：原根目录阶段性报告。

若后续产生新的阶段性分析，请在其结论合并进 `docs/STAGE_DELIVERY.md` 后归档，不要重新形成多个并行的“最新”入口。
