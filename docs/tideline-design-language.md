## 1. 设计哲学

IRIP 的界面表达三个词：**流动、深邃、克制**。

- **流动**：平台浮在一片"数据之海"上。潮汐波浪缓慢漂移、光带扫过、气泡上浮——流动感来自背景与渐变，不来自前景干扰。
- **深邃**：浅冰蓝画布之下有深度。深度用大号描边水印、透明层次和深潮蓝的文字与线条表达，不用黑色压场，也不用实色块砸出来。
- **克制**：时髦但不喧闹。每个装饰元素都必须回答"为什么在这里"，回答不了就删掉。

第一眼目标：让平台区别于一切常规 Ant Design 管理后台，形成一个独立、可识别的科研数据空间。

本语言参考了《女神异闻录3 Reload》UI 中"水"的意象与大胆的字体层级，但不复刻其具体界面、图标、字体或构图；全部视觉元素为原创实现。

## 2. 审美红线（三条，均为实战教训）

### 2.1 不得使用生硬几何切割

斜切（clip-path 平行四边形）、尖锐折角、skew 变换——一律禁止。它们是割裂的、机械的几何语言，与"流动感"本质上冲突。所有切割用曲线、圆角、渐变过渡代替。

> 教训：v2 初版（af60786）全套斜切被否决——"太生硬，我要的是流动感"。

### 2.2 不得使用大面积实色撞色块

深潮蓝色块不得作为独立底色块贴在浅冰蓝画布上（品牌块、选中带、Hero 块均禁止）。深浅对比必须通过**渐变、透明度、玻璃光泽**连续过渡。深潮蓝只允许出现在：文字、线条、渐变中。

> 教训：深蓝品牌块 + 亮青数字的撞色组合被否决——大面积实色块在浅底上是一块突兀的"胎记"，不是深度。

### 2.3 装饰稀缺性：一种签名，全平台只用一次

同一个装饰元素出现的次数越多越贬值。出现一次是签名，出现四次是贴纸。每个装饰必须回答"为什么在这里"；内容已经自足的地方必须留白，空不等于缺装饰。

> 教训：GradLine 渐变线曾同时用于登录页、logo、Hero 数字、时钟四处，被收敛到仅保留 logo 下方一条——因为那一处承担品牌下划线的结构语义，其他三处都是画蛇添足。

## 3. 色彩体系

### 3.1 画布（大面积）

| 语义 | 值 | 用途 |
|---|---:|---|
| canvas.start | `#A6D3E6` | 页面空间渐变起点 |
| canvas.middle | `#CBE4EE` | 主内容背景 |
| canvas.end | `#EAF6F9` | 亮部留白 |

### 3.2 深潮锚点（仅文字/线条/渐变）

| 语义 | 值 | 用途 |
|---|---:|---|
| abyss.deep | `#0B4A6F` | 标题、选中文字、强调 |
| abyss.deeper | `#07334E` | 渐变终点 |
| 标题实色 | `#0C4667` | 页面大标题 |

### 3.3 潮流青（数据流与光泽）

| 语义 | 值 | 用途 |
|---|---:|---|
| current.bright | `#17B8CE` | 数据流、强调线、渐变色标 |
| current.onDeep | `#4FE0EC` | 深底上的亮青文字（仅限小面积） |

### 3.4 主操作与状态

- action：`#0E5B84 / #0B4A6F / #07334E`（primary/hover/active）
- 状态色沿用 v1 语义字典（success `#10B981`、warning `#9A6818`、danger `#A53D52`、info `#245F9A`、special `#6655A4`），暖色只用于状态与风险。

### 3.5 签名渐变

- 文字渐变（ocean-flow-text）：`115deg, #0C4A6B → #0E6A92 → #17B8CE`
- 直线渐变（GradLine）：`90deg, rgba(14,91,132,.9) → rgba(23,184,206,.6) → 透明`
- 按钮渐变：`115deg, #0E5B84 → #1296AC → #17B8CE`

## 4. 签名元素清单

每个签名元素注明：定义、用法、**出现位置限制**。

### 4.1 潮汐背景（OceanBackdrop）

双层 SVG 波浪（周期 1200、200% 宽漂移无缝循环）+ 对角数据流光带 + 5 颗圆形气泡 + 半调网点 + 两处柔光。运动层 ≤ 3，reduced-motion 全部静止。

- **必须**：波浪 SVG 宽度 200% 时设置 `max-width: none`（覆盖 global.css 的 `svg { max-width: 100% }`，否则漂移露底）。
- **必须**：波峰亮线使用开放路径（闭合路径描边会画出竖直边）。

### 4.2 水印大字（.ocean-watermark）

超大描边空心英文（`-webkit-text-stroke`），置于页头标题背后或登录页品牌区。每个页面**最多一个**单词；描边透明度 ≤ 0.13，实心版透明度 ≤ 0.05。

### 4.3 渐变文字（.ocean-flow-text）

深潮蓝→潮流青的 background-clip 文字。**仅限**：IRIP 品牌字、DataHero deep 核心数字。普通标题禁止（用实色 #0C4667）。

### 4.4 水光玻璃（选中态材质）

浅青透明渐变底 + 1px 青边 + 内嵌顶部高光 + 细投影。**仅限**：侧栏导航选中项、页头胶囊页签选中项。导航选中项额外有左缘 3px 圆头渐变潮位线。

### 4.5 GradLine 渐变直线

左深右浅圆头渐变细线。**全平台仅一条**：侧栏 logo「工业研究智能平台」下方，承担品牌区与导航的结构分界。任何其他位置不得新增。

### 4.6 编号系统

导航项 = 编号（01–05，mono）+ 中文名 + 英文小标（BOARD/BUILD/OPS/APPS/GOV）。登录页能力列表沿用编号 + 圆头短横。

### 4.7 圆头题注条（.ocean-title-ribbon）

页面标题左侧 4px 圆头渐变竖条（深潮蓝→潮流青，带微光晕）。页面标题专用，每标题一个。

### 4.8 EcgLine 心电图

系统健康专用图示：底层淡色完整波形 + 亮纹沿波形跑动（stroke-dashoffset 循环），颜色随健康语义（success/warning/danger）变化。stretch 模式（`preserveAspectRatio="none"` + `vectorEffect="non-scaling-stroke"`）作看板系统健康面板主视觉。**仅限**健康/监控语义场景。

### 4.9 SiderClock 侧栏时钟

侧栏底部：27px 等宽大号时间（秒级刷新、tabular-nums）+ 12px 日期星期 + 10px 版本行。侧栏专用。

## 5. 组件规范

| 组件 | 用法 | 禁忌 |
|---|---|---|
| OceanPanel | default/strong/structural 三层材质，圆角 6–10 | 不得叠加实色深底变体 |
| DataHero | deep 变体 = 超大渐变数字（88px/800），无底无框 | 不得加底色块、边框、下划线 |
| MetricStrip | 指标卡圆角 10 + 顶部水光渐变线，数字 `#0E5B84` | 不得做同宽卡片墙 |
| PageIntro | 题注条 + 实色标题 + 可选 watermark | 水印每页最多一个 |
| 页头胶囊页签 | 圆角 999，选中 = 水光玻璃 | 不得用实色填充选中 |
| 登录卡 | 圆角 14 + 顶部渐变光边 + 玻璃模糊 | 不得斜切角 |
| 主按钮（登录） | 深潮→潮流青渐变 + 圆角 10 | 不得平涂深蓝 |

表格、表单、连续任务区保持稳定端正：标准 surface、标准行高、无装饰。治理/审计页装饰强度最低。

## 6. 动效规范

- 进入：`ocean-tide-enter` 纯垂直浮上（14px → 0，520ms），阶梯延迟 d1–d4（60ms 级进）。**禁止** skew、斜向滑入、过冲刺。
- 背景：波浪漂移 38s/56s 线性循环；光带 26s 呼吸；气泡 18s 上浮。
- 反馈：hover 120ms / 控件 180ms / 面板 320ms，统一 `cubic-bezier(0.22, 1, 0.36, 1)`。
- reduced-motion：背景全静止，内容仅 80ms 透明度过渡，EcgLine 亮纹静止。

## 7. 布局规范

- 侧栏 216px 固定：品牌区（波纹字标 + 渐变字 + 唯一 GradLine）→ 编号导航 → 底部 SiderClock。
- 页头 sticky：英文索引（mono 小字）+ 题注条 + 44px 实色大标题 + 右侧操作；水印在标题背后右对齐；胶囊页签第二行。
- 看板：Hero 渐变数字 + MetricStrip 非对称行 → 趋势/占比三栏 → **最近作业与系统健康两栏等高**（grid stretch + 面板 height 100%，健康面板内容 flex 填满）。
- 内容最大宽 1680px 居中，边距 clamp(20px, 1.4vw, 32px)。

## 8. 图表规范

ECharts 色板以深潮蓝起调：`#0E5B84, #17B8CE, #6FA9BE, #6655A4, #14765E, #9A6818`。背景透明、坐标轴灰蓝、tooltip 用 strong surface。不伪造趋势与总量。

## 9. 可访问性与响应式

- 正文对比度 ≥ 4.5:1；状态不只依赖颜色（文字/图形双编码）。
- < 900px：侧栏折叠、登录页品牌区隐藏。
- 键盘焦点 2px 可见；reduced-motion 全量降级。

## 10. 实施约束

- 不新增运行时依赖；视觉全部用 CSS + 内联 SVG 实现。
- 表格/对话/流程滚动区不用实时 backdrop-filter。
- 质量门槛：`npx tsc --noEmit` 零错误；`npx vitest run` 不劣于基线（当前基线：34 过 / 3 个 main 上预存在的 MentionInput 失败）；`npm run build` 通过。
